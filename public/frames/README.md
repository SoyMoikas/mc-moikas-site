# Image frames

Put frame PNGs in this folder, push, then in **Admin → Store → New item → Avatar frame**
set **Image** to `/frames/<file>.png`.

## Size
- Canvas **384 × 384 px**, transparent PNG.
- The avatar is the **centre 256 × 256** square (from 64 px to 320 px). Keep it transparent.
- Draw the frame in the **64 px margin** around it. You can overlap the picture by up to ~16 px.
- Bigger is fine if you keep the same proportions, e.g. 768 × 768 with the avatar at 128–640 px.
- Keep files small (under ~150 KB). Avatars show at 28–64 px on screen, so bold shapes beat fine detail.
- Hats sit over the top-right corner, so don't put the most important detail there.

`frame-template.png` has the guides drawn on it (red = avatar edge, orange = max overlap, purple = where hats sit). Use it as a bottom layer and hide it before exporting.
`example-gold.png` is a finished example.
