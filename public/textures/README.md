# Texture tiles

Small images that repeat to make patterns. Use them for wallpapers and banners (Admin → Store → item →
Image `/textures/stone.png`, tick **Tile**), or for a theme's block texture (texture "Image (tile)").

- Any square size works: 16×16 or 32×32 for pixel art, 128–512 px for painted textures.
- Make the edges match so the seams don't show.
- For pixel art, also tick **Pixel art** so it stays crisp when it's shown bigger.
